# 📈 Análisis de Datos — Laboratorio Amadita

Proyecto de análisis de datos desarrollado en Microsoft Excel como ejercicio académico basado en un escenario simulado de un laboratorio clínico. Incluye análisis de Centro de Contacto, Sucursales y Facturación, con tablas dinámicas, gráficos interactivos y fórmulas avanzadas.

> ⚠️ Los datos utilizados en este proyecto son ficticios y fueron creados únicamente con fines de práctica y demostración.

---

## 📌 Descripción

Este proyecto modela el análisis operativo y financiero de un laboratorio clínico, permitiendo visualizar el rendimiento por sucursal, el comportamiento del centro de contacto y los indicadores de facturación mediante dashboards construidos en Excel.

## 🛠️ Tecnologías utilizadas

- **Microsoft Excel**
- **Tablas dinámicas** — resumen y análisis por dimensiones
- **Gráficos** — visualización de tendencias y comparativas
- **Fórmulas avanzadas** — cálculos y métricas automáticas

---

## 📐 Contenido del archivo

| Hoja | Descripción |
|---|---|
| Centro de Contacto | Análisis de llamadas, atención y rendimiento del equipo |
| Sucursales | Comparativa de desempeño por sucursal |
| Facturación | Indicadores financieros y análisis de ingresos |

- Análisis de datos operativos y financieros en Excel
- Construcción de tablas dinámicas para resumen ejecutivo

- Análisis multidimensional (sucursales, contacto, facturación)

## 🚀 Cómo usar este proyecto

1. Clona el repositorio:
   ```bash
   git clone https://github.com/ingmartinez031/excel-analisis-amadita.git
   ```
2. Abre el archivo `Ejercicio de Analisis de Datos.xlsx` en Microsoft Excel
3. Explora las hojas de Centro de Contacto, Sucursales y Facturación
4. Interactúa con las tablas dinámicas usando los filtros disponibles
